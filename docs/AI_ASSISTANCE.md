# Tool assistance and responsibility

The team used AI assistance for implementation, test development, code review,
troubleshooting and documentation drafting, including report and slide drafts.
The repository records the resulting source changes and validation evidence.

Nguyễn Minh Quân coordinates authentication, users and integration. Phạm Văn Tú
is responsible for catalog and frontend work. Lê Nguyễn Vạn An is responsible
for loans, administration and API validation. Each member must review and be
able to explain the material submitted under their responsibility.

Git authorship identifies the person responsible for a commit; it does not mean
that every line was written without assistance. Existing author records and test
results must remain accurate. The team must follow the instructor's applicable
rules for tool use and disclosure and verify references, figures and claims
before submission.
