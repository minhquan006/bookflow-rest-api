## Required material

| Item   | Requirement                                                                                                                          |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| Report | English Word and PDF, 20–60 pages excluding covers and appendices, faculty format, references and figures                            |

demo component receive zero. Late submission incurs one point per day, including
a partial day. Consult the original assignment for the full rubric.

## Before uploading

1. Review the Word and exported PDF, including cover details, contents, figure
   and table lists, page numbers, references and appendix.
2. Check each implementation claim against the source and label historical
   screenshots and tests with their actual scope.
3. Rehearse the demo on the source version being submitted. Make the local demo
   password available through the documented setup; never publish real secrets.
4. Play the complete recording and check sound, readability, duration and all
   three speakers. Slides alone do not replace the video.
5. Package source without `.git`, dependencies, build output, local environment
   files, credentials or personal-data dumps. Include all three lockfiles.
6. Open every deliverable after copying/uploading it and verify the platform's
   submission confirmation. Do not assume a GitHub link replaces a required file.
